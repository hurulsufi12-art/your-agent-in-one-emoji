An agent, in one emoji: 🧩

The puzzle piece — an agent takes a task apart, matches the pieces,
and completes the picture. One glyph, no words, no explanation.

## Entry

`main.py` (Python 3.13, stdlib only) writes exactly one emoji to
`/output/entry.txt`: 🧩 (U+1F9E9), 4 bytes of UTF-8, no trailing newline.

```
python3 -P -s main.py
```
